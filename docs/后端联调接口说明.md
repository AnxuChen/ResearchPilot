# Research Pilot 后端联调接口说明（2026-02-27）

本文档与当前代码实现保持一致，按 `/backend/src/index.js` 实际接口整理。

## 1. 服务地址与健康检查

- Base URL（线上）：`http://111.229.204.242:8081`
- 健康检查：
  - `GET /healthz`

示例：

```bash
curl http://111.229.204.242:8081/healthz
```

## 2. 鉴权方式

- 请求头：`Authorization: Bearer <token>`
- `token` 获取方式：
  - `POST /auth/wx-login`
  - `POST /auth/email-register`
  - `POST /auth/email-login`

未携带或无效 token 时，接口返回 `401`。

## 3. 接口总览（当前已实现）

### 3.1 认证与用户

- `POST /auth/wx-login`：微信登录（`code` 必填）
- `POST /auth/email-register`：邮箱注册并返回 JWT
- `POST /auth/email-login`：邮箱登录并返回 JWT
- `GET /users/me`：获取当前用户资料
- `PUT /users/me/profile`：更新资料（昵称、头像、徽章、语言）
- `GET /users/me/liked-papers`：获取已收藏论文

### 3.2 项目管理（Conferences）

- `GET /projects/conferences`：获取会议卡片列表（首次会自动种子默认卡片）
- `POST /projects/conferences`：新增会议卡片
- `PATCH /projects/conferences/:id`：更新会议卡片
- `DELETE /projects/conferences/:id`：删除会议卡片

### 3.3 论文流与详情

- `GET /papers/feed`：论文流
- `GET /papers/:id`：论文详情
- `POST /papers/:id/ai-reading`：AI 阅读摘要（`language=en|zh`）
- `POST /papers/:id/action`：论文行为（`PASS|MARK|READ`）
- `POST /papers/:id/like`：收藏/取消收藏（支持 toggle）
- `GET /papers/:id/comments`：评论列表
- `POST /papers/:id/comments`：创建评论
- `POST /papers/:id/comments/:commentId/like`：评论点赞/取消点赞

### 3.4 个人页

- `GET /profile/dashboard`：个人统计数据

### 3.5 Lab 工具

- `GET /lab/recent-reading`：最近阅读

- AcademicPls
  - `POST /lab/academic-pls`
  - `GET /lab/academic-pls/recent`
  - `DELETE /lab/academic-pls/recent/:recordId`

- Citations
  - `POST /lab/citations/format`
  - `GET /lab/citations/recent`
  - `DELETE /lab/citations/recent/:recordId`

- Data Viz（异步任务）
  - `POST /lab/data-viz/tasks`
  - `GET /lab/data-viz/tasks/:taskId`
  - `GET /lab/data-viz/recent`

- Review Simulator（异步优先）
  - `POST /lab/review-simulator/tasks`
  - `GET /lab/review-simulator/tasks/:taskId`
  - `GET /lab/review-simulator/recent`
  - `DELETE /lab/review-simulator/recent/:recordId`
  - `POST /lab/review-simulator`（同步兼容接口）

## 4. 关键行为说明

### 4.1 论文流数据源

- `/papers/feed` 当前优先使用 **OpenAlex**。
- OpenAlex 失败时回退本地缓存，响应 `meta.source=local_cache` 且 `meta.fallback=true`。

### 4.2 LLM 调用策略

- 按 `LLM_MODEL_POOL` 串行尝试（非并发）。
- 某个模型成功即返回，不继续尝试后续模型。
- 当前默认模型池（代码默认值）：
  - `gpt-5.2-chat-latest,minimax-m2.5,gpt-5`

### 4.3 Lab 输入大小限制（服务端）

- AcademicPls：`text` 最大 `2000` 字符
- Citations：`text` 最大 `12000` 字符
- Review Simulator：上传 `pdf/txt/md`，上限约 50MB（前端控制）
- Data Viz：上传 `csv/json/xls/xlsx`，上限约 50MB（前端控制）

### 4.4 异步任务状态

- `PENDING`：已创建
- `RUNNING`：执行中
- `DONE`：完成
- `FAILED`：失败

## 5. 常用联调示例

### 5.1 邮箱注册

```bash
curl -X POST "http://111.229.204.242:8081/auth/email-register" \
  -H "Content-Type: application/json" \
  -d '{
    "email":"alice@example.com",
    "password":"Passw0rd!123",
    "fullName":"Alice",
    "fieldOfStudy":"NLP"
  }'
```

### 5.2 拉取论文流

```bash
curl -H "Authorization: Bearer <token>" \
  "http://111.229.204.242:8081/papers/feed?page=1&pageSize=12&keywords=large%20language%20model"
```

### 5.3 引用格式化

```bash
curl -X POST "http://111.229.204.242:8081/lab/citations/format" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "text":"Smith J. Deep learning for NLP. Journal of AI. 2024;12(3):1-10.",
    "style":"APA7"
  }'
```

### 5.4 创建 Review Simulator 异步任务

```bash
curl -X POST "http://111.229.204.242:8081/lab/review-simulator/tasks" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "fileName":"draft.pdf",
    "mimeType":"application/pdf",
    "extension":"pdf",
    "fileUrl":"https://<cloud-temp-url>"
  }'
```

- `OPENALEX_API_KEY`

- `LLM_MODEL_POOL`（模型优先级列表）
- `LLM_TIMEOUT_MS`
- `LLM_PER_MODEL_TIMEOUT_MS`
- `CITATION_LLM_TIMEOUT_MS`

## 7. 联调排查建议

- `401 missing_token/invalid_token`：检查 `Authorization` 请求头。
- `paper_not_found`：先确认该 paper 是否已进入本地 `papers` 表。
- `citation_format_failed` 且前端提示超时：优先检查 LLM 可用性与 `CITATION_LLM_TIMEOUT_MS`。
- AnyService 场景下长任务超时：优先使用异步任务接口（Review/DataViz）。
