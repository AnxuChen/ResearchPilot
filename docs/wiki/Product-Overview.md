# 产品概览

## 一句话定位

Research Pilot 是一个聚焦科研流程的一体化微信小程序，把文献检索、阅读、引用处理、投稿管理和 AI 工具集中在同一个入口。

## 产品目标

- 降低科研工具切换成本。
- 缩短从“检索文献”到“形成可提交内容”的路径。
- 用可落地的 AI 能力辅助日常科研任务，而不是替代流程管理。

## 核心能力矩阵

| 模块 | 核心能力 | 典型场景 |
| --- | --- | --- |
| Auth | 微信登录、邮箱登录、JWT 会话 | 用户身份与会话管理 |
| Library | 论文检索、推荐流、收藏与阅读状态 | 快速建立个人文献池 |
| Paper Detail | 评论互动、点赞、AI Reading 摘要 | 论文讨论与快速理解 |
| Projects | 会议卡片新增/编辑/删除、截止倒计时 | 投稿排期与任务看板 |
| Lab: AcademicPls | 学术文本润色 | 稿件语言提升 |
| Lab: Citations | 引用格式转换 | 参考文献标准化 |
| Lab: DataViz | 上传数据并异步生成图表 | 快速可视化 |
| Lab: Review Simulator | 稿件上传与异步审稿模拟 | 提前发现评审风险 |
| Profile | 收藏管理、偏好设置、徽章、资料维护 | 个人中心能力 |

## 目标用户

- 研究生与青年科研人员。
- 有投稿计划、需要跟踪会议与截止日期的用户。
- 需要 AI 辅助写作与分析，但希望保留清晰科研流程的用户。
